# always follow these code principles:

* Use as much C++ built in features as possible (STL, cpp headers, ...)
* handle exceptions everywhere.
* Optimization, follow best coding standards (no unnecessary copies,  free your functions, header seperation, ...)
* always write unit tests and documentation for your code.
* use oop only when necessary.
* use git branches.
* use .hpp for class declarations, and .cpp  files for class implementation, also .tpp for templates.

happy coding.
